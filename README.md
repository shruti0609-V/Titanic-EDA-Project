# Titanic Dataset - EDA Project

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python libraries.

## Tools Used:
- Pandas
- Matplotlib
- Seaborn
- Plotly

## Steps Performed:
- Summary statistics
- Null value handling
- Visualizations (histograms, boxplots, pairplots)
- Correlation analysis
- Feature-level observations

## Dataset:
[Titanic Dataset (Kaggle)](https://www.kaggle.com/datasets/yasserh/titanic-dataset)

## Findings:
- Female passengers had higher survival rate.
- Class and fare strongly influence survival.
- Age has mild right-skew.
